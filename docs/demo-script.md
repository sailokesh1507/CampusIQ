# CampusIQ 3–5 minute demo script

1. **Frame the problem (30 seconds).** “Faculty signals are distributed across academic, attendance, learning and placement records. CampusIQ makes the next support conversation more informed. This is synthetic demo data and heuristic decision support; faculty retain judgment.”
2. **Show the overview (45 seconds).** Point out the live student count, median score, coverage, review priority and independent support signals. Explain that cards recalculate from the current filter.
3. **Find a cohort (45 seconds).** Open Students and filter/search `placement` or select the high-academic/low-placement segment. Show that students are prioritized by evidence, not a hardcoded dashboard number.
4. **Explain one profile (60 seconds).** Open `SYN-007`. Show score, component contributions, coverage, inputs absent, placement evidence and the plain-language rule. Mention that missing values are “not supplied,” never zero.
5. **Close the loop (45 seconds).** Open Interventions, create a placement preparation action with owner, due date and observed rationale. Move it in progress, add a note, and show the persisted timeline.
6. **Explain guardrails (30 seconds).** Open Methodology. Show weights, reweighting, 60% minimum coverage and heuristic limitations. Optionally validate the CSV template and show row-level errors.

Closing line: “CampusIQ does not decide for faculty. It turns integrated campus data into a transparent prompt for a human-reviewed next step.”
