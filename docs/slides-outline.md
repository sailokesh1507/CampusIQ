# Slide outline (5–6 slides)

1. **The gap:** campus signals live in separate systems; support arrives late or without context.
2. **CampusIQ loop:** integrated data → deterministic insight → explainable evidence → faculty intervention → follow-up.
3. **Data + guardrails:** seven domains, stable student IDs, CSV validation, missing-data coverage, synthetic-only demo.
4. **Score + segments:** `heuristic-v1`, component weights, independent support flags, overlapping cohort rules.
5. **Working product:** overview, explorer/profile, import center and intervention workbench screenshots or live walkthrough.
6. **Impact + limits:** faster triage and better conversation context; faculty judgment required, no validated prediction, no real PII, no automated adverse action.
