# Fictional campus sample

[`campusiq-fictional-campus.csv`](./campusiq-fictional-campus.csv) is a realistic-looking but entirely fictional CampusIQ import fixture.

- Names are invented demo identities and are not real student records.
- Measurements are synthetic values designed to exercise strong, support-needed, placement-ready, and insufficient-data cohorts.
- The file follows the unified CSV contract in [`../data-dictionary.md`](../data-dictionary.md).
- It is safe to use in the Import Center for a presentation or local rehearsal.
